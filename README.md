# Детская больница «Бота», Астана

Сайт современной детской больницы на **Next.js 15 (App Router) + React 19 + TypeScript + Tailwind CSS 3 + Lucide**.
Готов к деплою на Vercel без дополнительных настроек.

## Что внутри

| Страница | Адрес | Что на ней |
| --- | --- | --- |
| Главная | `/` | Hero с кнопками быстрого действия, «Почему мы», врачи, подарок за смелость, карта-ссылка |
| Врачи | `/doctors` | Сетка карточек с фильтром по специальности |
| Игровые зоны | `/play` | 4 игровые комнаты, аниматоры, программа «Подарок за смелость», интерактивный сундучок |
| Контакты | `/contacts` | Интерактивная карта Google с переключением филиалов, адреса, маршрут |
| Онлайн-запись | `/appointment` | Филиал → специальность → врач → дата → время → данные ребёнка и родителя |
| Личный кабинет | `/account` | Вход и регистрация, список записей, отмена записи |

Вход и регистрация также доступны в модальном окне из шапки сайта.

## Запуск

Нужен Node.js 18.18 или новее.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # проверка production-сборки
npm run lint
```

## Деплой на Vercel

1. Загрузите папку в репозиторий GitHub.
2. На vercel.com выберите **Add New → Project** и подключите репозиторий. Framework Preset определится сам (Next.js).
3. По желанию добавьте переменную окружения `NEXT_PUBLIC_SITE_URL` с адресом сайта (используется в sitemap и метаданных).
4. Нажмите **Deploy**.

## Что нужно заменить перед запуском

Всё содержимое лежит в двух файлах, править код компонентов не нужно:

- `src/lib/site.ts`: название, телефон, e-mail, часы работы, меню.
- `src/lib/data.ts`: филиалы (адреса для карты), специальности, врачи, игровые зоны, подарки.

**Адреса, телефоны, e-mail и имена врачей в проекте вымышленные**, их нужно заменить реальными данными клиники.

### Фотографии

Сейчас вместо фото показаны нарисованные иллюстрации (врачи, здание, игровые комнаты). Чтобы вывести фотографию:

- Врач: заполните поле `photo` у нужного врача в `src/lib/data.ts`.
- Игровая комната: заполните поле `photo` у нужной зоны.

Домен `images.unsplash.com` уже разрешён в `next.config.mjs`. Для собственных фото положите файлы в `public/` и укажите путь вида `/doctors/aigerim.jpg`, либо добавьте нужный домен в `remotePatterns`. Если фото не загрузится, сайт покажет иллюстрацию. Проверьте лицензию на фото и согласие людей на публикацию.

## Важно: личный кабинет и запись работают в демо-режиме

Чтобы сайт работал на Vercel без базы данных, аккаунты и записи хранятся в `localStorage` браузера. Пароль сохраняется в виде соли и хеша, но это **не заменяет серверную защиту**. Данные видны только в том браузере, где их создали, а занятость времени у врачей имитируется.

Для рабочей системы замените:

- `src/components/auth/AuthProvider.tsx`: функции `login`, `register`, `logout` (например, на Auth.js, Clerk или Supabase Auth);
- `src/lib/appointments.ts`: `submitAppointment`, `listAppointments`, `cancelAppointment`, `availableSlots` (на запросы к вашему API или к расписанию МИС).

## Структура

```
src/
  app/            страницы, layout, sitemap, robots, 404
  components/
    account/      личный кабинет
    appointment/  форма записи
    auth/         провайдер авторизации, формы, модальное окно
    doctors/      карточки, сетка, иллюстрация врача
    home/         блоки главной страницы
    layout/       шапка, подвал, логотип
    map/          карта Google и стилизованная карта-ссылка
    play/         игровые зоны, сундучок смелости
    ui/           кнопки, поля, секции
  lib/            данные, настройки, запись на приём, localStorage
```

## Дизайн и доступность

- Палитра: мягкий розовый (`rose-50/100/300`), голубой (`sky-50/100/200`) и мятный (`mint-*`), основной текст цвета `ink` (`#33304f`).
- Шрифты: Unbounded для заголовков, Nunito для текста (оба с кириллицей, подключены через `@fontsource`, без запросов к Google Fonts).
- Mobile-first, три брейкпоинта (телефон, планшет, ПК).
- Семантическая разметка (`header`, `nav`, `main`, `section`, `article`, `footer`, `address`), ссылка «Перейти к содержимому», видимый фокус, подписи у всех полей, `aria-live` для ошибок и результатов.
- Анимации отключаются при настройке «уменьшить движение».
